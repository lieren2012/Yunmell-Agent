# 单企业部署兼容评估

2026-10-12，第 15 节产品决策覆盖旧的多企业入口。

## 实际故障

b8 桌面设置仅用于健康检查，未传给 Python 身份适配层。本机数据库没有组织或团队。注册表单仍要求 slug，没有提交状态、异常捕获或返回入口。把服务器 URL 填入 slug 后，实际本机请求返回 HTTP 405，错误 Promise 未处理。注册不能作为登录状态，也不能用 URL 充当企业名称。

## 现有数据与迁移

部署路径 `/www/wwwroot/lee.yunmell.agent`，独立数据目录 `/www/wwwroot/lee.yunmell.agent-data`，端口 6602。只读盘点：schema 26，4 个账号、2 个组织、2 个团队、3 条成员关系、3 条申请、2 个 Provider、1 个智能体和 1 条会话。

新增迁移仅增加注册开放字段、申请查询凭据与桌面身份映射。保留全部原组织、团队、成员、账号、申请、会话和 Provider。部署组织及默认团队通过持久化设置引用已有 ID；管理员可改显示名称。已有多个组织时优先选择成员最多的组织，同数按原创建顺序；记录选择结果，后续名称或成员变更不重新选择。历史成员关系不合并、不改归属；历史策略仍作为约束。新注册进入固定部署团队。

客户端只保存服务地址，读取服务名称。远端账号以“管理地址 + 远端用户 ID”映射到新增本机账号，禁止用用户名匹配覆盖旧本机管理员。更换地址时旧身份失效，旧会话及工作区保留。远端令牌在本机后端加密保存，不送入前端；本机 JWT 仍由本机服务签发并验证。

默认模型通过无状态模型转发调用；企业 Provider 密钥保留在管理端，消息和工具运行数据在客户端持久化。管理端不创建桌面会话或执行本机工具。模型、审核、权限及配额以管理端当前配置为准。

部署前做一致性数据库及程序备份；升级后核对旧记录 ID、数量与归属。仅更新本项目容器和 6602 服务，回滚保留升级后的数据备份。
